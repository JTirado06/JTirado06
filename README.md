## Featured Projects

### [Reaction Duel](https://github.com/JTirado06/reaction-duel)

A two-player reaction game built with an ELEGOO UNO R3, push buttons, an LED, and a 16×2 LCD. Players compete in first-to-five matches with reaction timing, false-start penalties, and tie handling. The firmware uses a finite-state machine, independent button debouncing, and elapsed-time checks with `millis()`.

**Technologies:** Arduino C++, digital input/output, LiquidCrystal, software debouncing, breadboard prototyping

[View the build and gameplay demo](https://github.com/JTirado06/reaction-duel#demo)

### [Music Library Manager](https://github.com/JTirado06/music-library-manager)

A command-line music catalog and playlist manager written in C. It uses linked lists, stacks, binary search trees, AVL trees, and a max heap to organize songs and track listening activity.

**Technologies:** C, dynamic memory allocation, data structures, file I/O, Make

### [Blackjack](https://github.com/JTirado06/BlackJack)

A command-line Blackjack game written in Java using object-oriented programming. It features a shuffled 52-card deck, player and dealer logic, Ace value adjustment, and multiple playable rounds.

**Technologies:** Java, object-oriented programming
